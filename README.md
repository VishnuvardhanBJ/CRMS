# CRM Management System

A full-stack Customer Relationship Management (CRM) application for managing customers, leads, sales opportunities, sales records, tasks, support tickets, email campaigns, and SMS communications. The project uses a React frontend and a Spring Boot REST API with MySQL persistence.

## Features

- Customer and lead management with complete CRUD operations
- Sales and opportunity tracking
- Task assignment and status tracking
- Support ticket management
- Sales, customer, lead, ticket, email, and SMS analytics
- Email campaigns with optional attachments
- SMS messaging through Twilio
- Purchase and communication history views
- Responsive dashboard built with React, Bootstrap, Chart.js, and Recharts
